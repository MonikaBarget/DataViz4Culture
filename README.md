# DataViz4Culture

This repository contains small data visualization apps for cultural content &amp; humanities research. The apps are built with the open-source Python framework [Streamlit](https://streamlit.io) and [Stlite](https://stlite.net), a web assembly package that allows running the apps entirely in your browser. Please consider supporting the developers of these fantastic tools if you like what you see here! When running the apps, please give them a few seconds to load and finish the necessary installations.

Access the apps homepage: [https://monikabarget.github.io/DataViz4Culture](https://monikabarget.github.io/DataViz4Culture)

DataViz4Culture

This repository contains small data visualization apps for cultural content & humanities research. The apps are built with the open-source Python framework Streamlit and Stlite, a web assembly package that allows running the apps entirely in your browser. Please consider supporting the developers of these fantastic tools if you like what you see here!

I also owe a lot to the detailed tutorials provided by Sammi Rosser on HSMA - Web Apps with Streamlit in July 2024, especially Deploying to Github Pages with Serverless Streamlit (stlite).

When running the apps, please give them a few seconds to load and finish the necessary installations. The performance of the apps depends on your network connection, so using mobile devices can slow them down. Also, be aware that while web assembly technology processes all your data in the browser and does not send information to external servers, you should ideally work with sensitive data locally or in a protected research environment.

To navigate between apps, use the side-bar menu or the app buttons below. If you find any errors or have suggestions for improvement, open a Github issue.
